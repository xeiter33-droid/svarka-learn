# Сварка — учёба (svarka-learn)

Отдельный учебный сайт (не справочник): лекции, тесты, регистрация, прогресс и админ-панель.

Стилистика как у [svarka-app](https://xeiter33-droid.github.io/svarka-app/).

## Онлайн

Сайт готов в репозитории (`docs/` и ветка `gh-pages`).

**Сейчас открывайте зеркало** (GitHub Pages/Actions в major outage):  
https://cdn.jsdelivr.net/gh/xeiter33-droid/svarka-learn@gh-pages/index.html

После восстановления GitHub Pages заработает:  
https://xeiter33-droid.github.io/svarka-learn/

Статус инцидента: https://www.githubstatus.com/

## Курсы

1. Основы сварки  
2. Ручная дуговая сварка (РДС)  
3. Аргонодуговая сварка (TIG)  
4. Полуавтоматическая сварка (MIG/MAG)  
5. Материаловедение — расшифровка марок сталей и сплавов  

После каждого блока — проверочный тест.

## Запуск

```bash
npm start
```

Откройте http://localhost:4174

## Администратор

| Поле | Значение |
|------|----------|
| Логин | `admin` |
| Пароль | `AdminSvarka2024!` |

Админ-панель: `#/admin` — прогресс слушателей, задания, дополнение уроков, экспорт/импорт JSON.

> Данные хранятся в `localStorage` браузера. Между компьютерами — через экспорт/импорт.
